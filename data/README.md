# Veri

Bu klasörde yalnızca **küçük örnek ve test verileri** tutulur. Büyük ham deney verileri repoya konmaz (bkz. `.gitignore`), ortak bir sürücüde saklanır.

```
data/
├── samples/    Örnek dosyalar (repoda tutulur)
└── raw/        Ham deney verileri (repoya gönderilmez)
```

Dosya formatı: [../docs/veri-formati.md](../docs/veri-formati.md)
